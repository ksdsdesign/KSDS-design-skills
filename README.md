# KSDS Design Skills and Tools

Downloadable packages for the KSDS public resource gallery.

## Figma plugin

- [Motion Handoff R57](./motion-handoff-r57.zip) — Figma motion template and handoff toolkit. Download the ZIP, extract it, and import `manifest.json` as a development plugin in Figma. SHA-256: `3fe6ff1a4a9ddd25bb0e746cd1ba5d7e147758abadf4fc3330d09a0ee2fa8148`.

## Agent Skills

- [Accessibility Audit v1.0.1](./accessibility-audit-1.0.1.zip) — WCAG 2.2 AA testing workflow.
- [90s Comic Style v1.0.0](./90s-hiphop-style-main.zip) — retro American comic illustration style. Original work by [ASATELLITE](https://github.com/ASATELLITE/90s-hiphop-style); this ZIP is an unmodified snapshot of its public `main` branch from 2026-08-13.
- [Brand IP Designer v1.0.0](./ip-designer-1.0.0.zip) — brand character concept and extension workflow.

Extract each Agent Skill ZIP and place the Skill folder in your assistant’s skills directory. The comic-style snapshot extracts as `90s-hiphop-style-main`; rename that folder to `90s-hiphop-style` when installing.
